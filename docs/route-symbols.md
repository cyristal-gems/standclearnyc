# Public route symbols

Route labels follow MTA rider-facing terminology. The three shuttles display S, with their full names in selectors. Express variants display F, 6, and 7 inside diamond bullets; regular variants use circles. Source identifiers remain unchanged to preserve GTFS joins and live alert matching.

MTA sources checked October 3, 2026:

- [Shuttle line maps](https://www.mta.info/maps/subway-line-maps/s-line)
- [F line map](https://www.mta.info/maps/subway-line-maps/f-line)
- [6 local/Pelham express line map](https://www.mta.info/maps/subway-line-maps/6-line)
- [7 local/express line map](https://www.mta.info/maps/subway-line-maps/7-line)

Line Facts source links point to MTA route pages. Map geometry and station metadata continue to use official MTA data feeds.
